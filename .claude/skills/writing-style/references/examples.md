### 例 2

Before（AI っぽい）:

```
`w-screen` と `w-full` はどちらも横幅を 100% にするユーティリティですが、重要な違いがあります。
`w-screen` はビューポート幅を基準とするため、縦スクロールバーが存在する場合に横スクロールが発生する点に注意が必要です。
```

After:

```
ドキュメントをよくみると `w-full` というのもいました
違いは以下

- `w-full`： 親要素の幅 (width: 100%;)
- `w-screen`： ビューポートの幅 (width: 100vw;)

どっちも横幅いっぱいは同じなのですが違いがありました

例えば `100vw` (`w-screen`) は縦スクロールバーを含んだ幅を 100 とするので
縦スクロールバーが発生するとスクロールバーの幅分の横スクロールが発生してしまいます
```
